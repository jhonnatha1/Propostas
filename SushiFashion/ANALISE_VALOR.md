## 💡 FATORES DE AJUSTE DO PREÇO

### Aumentam o Custo ⬆️

1. **Complexidade adicionada**
   - [ ] Sistema de entrega/logística (+10-15%)
   - [ ] Integração com múltiplos gateways de pagamento (+10%)
   - [ ] Sistema de avaliações/reviews (+5-10%)
   - [ ] Programa de fidelização (+10%)
   - [ ] App mobile nativa (iOS/Android) em vez de web (+40-60%)

2. **Requisitos não-funcionais**
   - [ ] Performance extrema (< 1s) (+10%)
   - [ ] Suporte multi-idioma (+15-20%)
   - [ ] Internacionalização moeda (+10%)
   - [ ] Analytics/BI avançado (+10%)

3. **Serviços adicionais**
   - [ ] Migração de dados de sistema antigo (+5-10%)
   - [ ] Formação extensiva (€300-500/dia)
   - [ ] Suporte pós-lancamento (ver suporte e manutenção)
   - [ ] Marketing integrado (SEO, Google Business, Social)

### Diminuem o Custo ⬇️

1. **Simplificações**
   - [ ] Sem sistema de notificações por SMS (-5%)
   - [ ] Menu estático (sem admin) (-15%)
   - [ ] Pagamento apenas via Stripe (-5%)
   - [ ] Sem relatórios avançados (-10%)

2. **Re-utilização**
   - [ ] Usar template UI pré-feito (-15-20%)
   - [ ] Sistema de pedidos similar a existente (-20%)
