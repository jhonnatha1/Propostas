## 📋 Qual Documento Usar?

### **Para Apresentar ao Cliente:**
1. **ORCAMENTO_CLIENTE.md** - Documento completo e detalhado (RECOMENDADO)
2. **PROPOSTA_SIMPLES_CLIENTE.md** - Se o cliente quiser algo mais resumido
3. **COMPARATIVO_VALOR.md** - Se o cliente quiser entender melhor o valor do investimento

### **Para Uso Interno:**
- **ORCAMENTO_SITE_IMOBILIARIA.md** - Detalhamento técnico completo
- **CHECKLIST_PROJETO.md** - Acompanhamento durante o desenvolvimento
- **CONCEITOS_DESIGN.md** - Referência de design (após aprovação)

### **Dica:**
- Comece com **ORCAMENTO_CLIENTE.md** (documento principal)
- Se o cliente tiver dúvidas sobre o valor, envie também **COMPARATIVO_VALOR.md**
- Para enviar um PDF profissional, use **proposta-pdf.html** (abrir no navegador e clicar em "Download PDF")
- Use os documentos técnicos apenas para referência interna

### **Como Gerar o PDF:**
1. Abra o arquivo **proposta-pdf.html** no navegador
2. Clique no botão **"Download PDF"** no canto superior direito
3. Aguarde a geração do PDF
4. O PDF será baixado automaticamente
5. Veja mais detalhes em **INSTRUCOES_PDF.md**
